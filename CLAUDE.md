# mets

Neighborhood-based metaheuristics in Rust, a port of
[METSlib](https://github.com/baol/metslib). `DESIGN.md` is the reference for
the API and the reasons behind it; read the relevant section before changing
a public type or trait.

## Workflow

- **Work on a branch, never on `main`.** Start each piece of work from the
  latest `main` on a new, descriptively named branch, and push only that
  branch.
- Open a pull request only when asked, or ask when a branch is ready for
  review. Never merge; merging is the maintainer's.
- Before pushing, run the checks below and make sure they pass.

## Checks

```bash
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test                       # debug: also checks every committed delta
cargo test --release --all-targets
RUSTDOCFLAGS="-D warnings" cargo doc --no-deps
```

Debug builds check every committed move against two full evaluations, so
debug runs of the examples are much slower than release runs. That is
intended.

## Layout

- `src/`: the library. `model.rs` (Cost, Model, Move, Evaluated),
  `neighborhood.rs`, `state.rs`, `search.rs` (Search, Runner), `termination.rs`,
  and one file per algorithm family (`local_search.rs`, `tabu.rs`,
  `stochastic.rs`, `ils.rs`); `perm.rs` for permutation problems,
  `check.rs` for testing delta formulas.
- `examples/`: ports of the METSlib examples (`subset_sum`, `qap`, `vcp`).
- `tests/`: integration tests; shared toy models in `tests/common/mod.rs`.

## Conventions

- Keep `DESIGN.md` in sync with the code: when an API changes, update the
  section that describes it, and note design changes in §5 with the reason.
- The README example is compiled as a doctest (`src/lib.rs`), so keep it
  working.
- QAPLIB instances are not in the repository. `QAPLIB.md` is generated by
  `cargo run --release --example qap -- --qaplib DATA SOLN --restarts 200 --markdown`
  plus the explanatory header at its top; regenerate it rather than editing
  the table by hand, and update the summary numbers in `README.md` and
  `DESIGN.md` §4 to match.
- Benchmarks run on shared machines are noisy: report ranges from repeated
  runs, and say what was measured.
